# Zoning resources

Use the sibling [zoning-rule-engine](https://github.com/Strong-Towns-Detroit/zoning-rule-engine)
repository for zoning rules and its command reference.

For BZA cases, requested relief, and hearing outcomes, see the
[BZA guide](https://github.com/Strong-Towns-Detroit/strongtowns-data/blob/main/docs/bza.md).
Detroit graphics use the dataset versions in `strongtowns-data.lock.json`.

Parcel-use and zoning-use mappings are maintained in the data repository's
`pipelines/parcel-data` directory. Source citations and structured zoning models
are documented in the [Data SDK reference](https://github.com/Strong-Towns-Detroit/strongtowns-data/blob/main/docs/API.md).
