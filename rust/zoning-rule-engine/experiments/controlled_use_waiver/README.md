# §50-3-443 controlled-use waiver experiment

This fixture does not resolve the conflict between “any one” in the lead-in and
the terminal “and” joining the numbered findings. Every syntax preserves both
coordination signals and marks their interpretation unresolved.

The evaluator reports `AmbiguousCoordination` when exactly one finding is true,
`EligibleUnderBothReadings` when both are true, and always enforces the district
permission bar. This avoids turning an editorial or legal-review question into
an undocumented compiler choice.
