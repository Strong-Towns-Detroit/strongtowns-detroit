# §50-3-341 eligibility and spacing experiment

Nine pairings test two independent exceptions to delinquency-based
ineligibility and the prohibition triggered by at least two distinct legally
established regulated-use sites within 1,000 feet of the proposed site's
boundary, absent a waiver.

The one-off evaluator treats “within 1,000 feet” as inclusive and receives
already-computed boundary-to-site distances. It intentionally does not decide
which geometry on an existing site is the legally relevant distance target.
